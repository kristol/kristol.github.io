# kristol.github.io

Oldschool arcade hub for small weird static sites.

**Live:** https://kristol.github.io/

## Sites

| Path | What |
|------|------|
| [/bsExcuses](https://kristol.github.io/bsExcuses/) | Bullshit excuse generator |
| [/getreadyforxmas](https://kristol.github.io/getreadyforxmas/) | Christmas challenge calendar |
| [/hol_legyen_a_buli](https://kristol.github.io/hol_legyen_a_buli/) | Party vibe quiz |
| [/november22](https://kristol.github.io/november22/) | Party invite + mystery hunt |

## Add a new site

1. Create a folder at the repo root with an `index.html`
2. Add a new cabinet link in the root `index.html`
3. Push to `main` — GitHub Pages does the rest
